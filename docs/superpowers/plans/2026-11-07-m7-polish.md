# M7 Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish version 1: a Presets panel, undo/redo in the editor, and every loose end left by
M6 and the online test version.

**Architecture:** Presets and undo are pure functions in `src/lib/` (unit-tested), wired into
`Editor.tsx` through one `useReducer` history. Server fixes stay inside the existing login and
export-manager modules. Template fixes follow the M6 pattern: logic that can be pure moves into
the template's motion file (`templates/<id>/assets/*-motion.js`, testable from Vitest through
`createRequire`); shader-only changes are checked by eye in the 360p preview and by
`npm run check:templates`.

**Tech Stack:** Next.js 16 (App Router), React 19, TypeScript strict, Vitest (node environment),
HyperFrames 0.9.10 templates (plain WebGL and three.js), GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-07-m7-polish-design.md`

## Global Constraints

- Branch `feat/m7-polish`. Never commit to `main`. Merge only on the owner's explicit say-so.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Never commit `storage/`, `test-renders/`, audio, video or secrets. The repo is public.
- Run `npm run check` before every commit. Also run `npm run check:templates` before any
  commit that touches `templates/`.
- Templates:
  - draw only from the `hf-seek` time
  - no `Math.random()`, `Date.now()`, timers or `requestAnimationFrame`
  - WebGL render targets are 8-bit only
- Edit the toolkit only in `templates/shared/viz-toolkit.js`, then run `npm run sync:toolkit`.
- A template fix must not change how an export looks, except where its spec item says so: the
  grain pattern (hash change), the far ridge outline, and the tower colours. Preview-only
  fixes keep the export path (`PREVIEW_SCALE === 1`) byte-for-byte the same.
- Exact copy from the spec:
  - "This template has no presets."
  - "That request is too big."
  - "Waiting for the start-up check…"
- Limits: undo join window **1000 ms**, history **100** steps, login body **4096** bytes,
  password **256** characters.

## Review Focus

1. **Login body sent without Content-Length:** a chunked body over 4 KB must still get 413. The
   cap has to be enforced while reading, not only from the header (Task 3, test
   `refuses a chunked body over 4 KB`).
2. **The GPU check ends badly:** if it fails or throws, a waiting export must still start rather
   than hang forever (Task 4, test `a failed check still releases the waiting export`).
3. **Ctrl+Z in a text box:** with focus in the project name box or the title box, it must undo the
   typing, not the editor (Task 2, `isEditableTarget` tests on `INPUT type=text` and on an
   input with no type).
4. **Preset highlight with short colours:** a preset declaring `#f61` must still be highlighted
   when the value is `#ff6611`, and the other way round (Task 1, test
   `matches 3-digit and 6-digit colours`).
5. **Undoing a background change:** choosing a background sets both the picture and
   `showBackground`; one undo must restore both (Task 2, test
   `a compound change is one step`).
